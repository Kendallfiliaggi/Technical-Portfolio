# Bank Transaction Data Analysis

## Overview

This project uses anonymized bank account and transaction data to practice data cleaning, validation, transformation, and dataset integration using Python.

The goal was to combine multiple datasets and prepare the final data for further analysis.

## Tools Used

- Python
- Pandas
- NumPy
- Google Colab

## Project Data

The project used three datasets:

- Account data
- Transaction data
- District data

These datasets were combined to create a more complete transaction-level dataset.

## What I Did

- Imported and reviewed multiple datasets
- Checked file availability before loading data
- Reviewed column types and dataset structure
- Cleaned and validated data
- Transformed variables
- Combined account, transaction, and district data
- Prepared the final dataset for analysis

## What I Learned

This project gave me hands-on experience working with multiple datasets in Python. I practiced cleaning and validating data, working with different data types, combining datasets, and preparing data for analysis.
